# CodeAlpha_BasicChatbot
A simple rule-based chatbot built with Python for the CodeAlpha Internship.

## Features

- Responds to greetings
- Answers basic questions
- Provides predefined responses
- Uses if-elif-else conditions
- Uses a while loop
- Ends the conversation when the user types "bye"

## Technologies

- Python
